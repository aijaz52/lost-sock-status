A small TypeScript script that imagines what a misplaced sock might post as a 120-character status update. It was created for make.fun's “Funniest Lost Sock Status Update” bounty.

## Run it

From the project directory, run the script with:

```sh
node main.ts
```

It prints the sock's status update directly to your terminal.
